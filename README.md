# cpp-if-else-loops

# C++ Programs: If-Else and Loops

This repository contains simple C++ programs that demonstrate the use of conditional statements (if/else) and loops (for, while, do-while).

---

## 📂 Programs Included

### 1. `odd_even.cpp`
Takes a number from the user and checks whether it is odd or even.

### 2. `factorial.cpp`
Uses a loop to calculate the factorial of a number.

### 3. `table_printing.cpp`
Prints the multiplication table of any number entered by the user.

### 4. `guessing_game.cpp`
A simple guessing game where the user has to guess a random number.
